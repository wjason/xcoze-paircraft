# Working modes

Choose the approach based on what the user needs this round. A project can enter at any point.

| Goal | Start with | Possible handover |
| --- | --- | --- |
| Explore requirements | Extract scenarios from existing materials and compare options that affect outcomes | A one-page brief, first-version scope, or one primary flow |
| Prepare a review | Identify the reviewers, their question, and the prototype fidelity they need | An annotated sketch, editable design, or interactive prototype |
| Make a change or deliver | Check the baseline, change scope, things to preserve, and acceptance criteria | Updated source, actual verification results, and open questions |

- When the user wants to discuss first, lay out options and trade-offs. Let the user decide whether to make a prototype.
- If the user asks for a reversible draft, proceed with clearly marked assumptions and explain what the draft can help test.
- For a local prototype edit, locate the target, make the change, and verify it. If feedback challenges agreed users, scope, or core flows, identify the decisions it affects first.
- Tie new artifacts to the question at hand. Pick the least expensive format that lets the user make the decision.
